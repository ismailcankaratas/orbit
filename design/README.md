# Orbit original design concepts

The two reference images in `references/` were generated specifically as **Orbit concept art** for early product planning. They are not working UI screenshots, accurate datasets, or licensed third-party designs.

1. `orbit-overview-concept.png`: data-dense Overview with elegant orbital light trails, editorial heading, restrained gold, privacy-first metric cards, project ranking and activity lanes.
2. `orbit-live-agents-concept.png`: agent topology, recently observed work graph, recorded task list, systems health, and activity timeline. Its `Assign task`, `Pause flow` and similar wording is **concept-only and must NOT be implemented as functional or fake buttons** in the read-only MVP.

Creative direction: build a clearly original identity with orbit geometry and restrained luminous node clusters. No borrowed orchestral theatre, cartoon lemon, Avenox name, mascot, copyrighted screenshot, chart copy or signature layouts. Use real data for all product UI outside a visible synthetic demo mode.

Aim for desktop 1440x900 and excellent mobile adaptations at 390x844. The design reference is a storytelling moodboard, not a hard-coded composition.
